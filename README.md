# AmzFlow Admin

Personal Windows workspace for scraping Amazon.in product details and exporting product graphics through Photoshop.

## Download

[**Download AmzFlow Admin**](https://github.com/freakyrits/AmzFlow/archive/refs/heads/main.zip)

Extract the ZIP, then open `AmzFlow Admin/Open AmzFlow Admin.cmd`.

## Start

Open `AmzFlow Admin/Open AmzFlow Admin.cmd`.

## Updates

AmzFlow checks this repository whenever it opens. When a newer release is published here, it installs that version and restarts automatically.

To publish an update, change `APP_VERSION` in `amzflow_admin.py` to a higher number, then publish the change to the `main` branch.

## Requirements

The initial setup on each Windows computer needs the AmzFlow Python runtime, Playwright browser support, and Adobe Photoshop for PNG export. After setup, everyday updates are handled by the app.
